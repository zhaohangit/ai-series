# 设定图集与画布媒体交互进展

本轮继续已授权的参考站逆向与本地独立实现，未达到全站 UI、交互、前后端完全一致。以下只列实际实现和验证范围。

## 新增与修复

- 识别 146 个角色、97 个场景的 2,983 条设定图记录。新增缓存 442 张（499,885,715 字节），全部 243 个主体至少有一张缓存图。剩余 2,541 条保留明确的 `download_byte_limit` 状态；未缓存图片不会触发外部图片请求。
- 通过原站 bundle 验证“正面、背面、侧面、清晨”等类型标签，保留响应原始空值和标签证据。不推测缺失的分类名称。
- 预设详情支持主视觉/设定图预览与下载；导入时将缓存图上传为当前账号所有的媒体，编辑图集只包含成功导入的图片，完整来源目录另行保留。
- `POST /api/assets` 可选 `Idempotency-Key`，按账号隔离；相同请求重放返回同一素材、不同载荷 409、已删除素材 410。并发失败事务回滚其素材记录。浏览器丢失成功响应后的重试不重复创建素材或重复上传已完成的图片。
- 画布图片裁剪、视频裁剪/时间裁剪、音频截取和视频截帧会创建源节点右侧的关联输出节点及连线，保留原节点、父组相对坐标、版本快照与冲突检查。
- 关闭媒体面板后画布继续跟踪任务；只在提交以来没有新编辑时取回输出，有新草稿则保留草稿并提示查看记录。生成记录提供本地媒体预览/下载。
- 截帧按实际解码呈现时间和帧序号选择，支持验证过的变帧率保持区间和末帧。返回请求时间与实际帧时间；新增首帧、尾帧、当前帧快捷选择。时长精度、异常时间线及其他格式限制见后端媒体文档。

## 证据与验证

- 参考调查：`docs/canvas-media-evidence.md`，区分静态控制流和实际页面观测。
- 缓存：`node tools/cache-preset-galleries.mjs --verify` 校验全部 442 个文件的签名、长度及 SHA-256；前后端清单一致。清单 SHA-256 为 `adc5eb69e8997082b3e2ad4e781fcfec834b3c4ce662b42d196943eb0fd9e2ed`。
- 后端完整 PostgreSQL / Redis / MinIO / FFmpeg 测试：214 项通过；前端测试：83 项通过，生产构建通过。保留依赖弃用及大 bundle 提示。
- 图集浏览器：13 项检查，包含真实提交后响应丢失重试、字节一致、跨账号 404、未缓存占位、目录保留和账本不变。
- 变帧率部署验证：请求 0.05、0.5、1.95 秒，分别得到实际帧时间 0、0.1、1.9 秒；输出像素与相同部署解码器的对应源帧一致。
- 原有素材库 15 项、分镜媒体/画布历史 7 项、主体/故事板 9 项浏览器回归通过。
- 构建对应：`artifacts/verification/gallery-deployment.json` 核对网页构建字节，以及 api / worker 的 main、targets、media_tools、asset_creation 源文件哈希。
- 画布媒体专项 8 项全部通过：五种关联输出、原素材/父坐标/刷新、账本和幂等、关闭面板后自动接收并继续保存、脏草稿保护及历史预览下载。结果为 `artifacts/verification/canvas-media/browser-smoke.json`，页面脚本错误为 0。
